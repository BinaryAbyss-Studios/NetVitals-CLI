# Contributing

There are only a few rules to consider.

- Follow the commit convention as follows:
  - if there is more than one change, the change in the commit name should be the most impactful change
  - put other changes in the description
- no AI Slop allowed
- Test Before Committing/submitting them.

## Bug Reporting
- Choose one of the following Options:

  - 1 Report the Bug with OS, and other critical info in our discord community
  - 2 Report the Bug as an ISSUE in the github page.
